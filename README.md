### What I Do

- **Web applications:** scalable backends with Laravel and .NET, clean REST APIs and efficient MySQL data models.
- **Frontend engineering:** responsive, accessible and fast interfaces built with modern HTML, CSS and JavaScript.
- **Hosting & WHMCS:** custom themes, modules, client-area features and third-party integrations.
- **Infrastructure:** Linux servers, Nginx and Apache configuration, Cloudflare, caching and security hardening.
