### About Me

I'm a full-stack developer with **10+ years of experience** building and maintaining web products end to end. On the frontend I craft **pixel-perfect, responsive and accessible** interfaces with modern JavaScript frameworks and utility-first CSS; on the backend I work with **PHP, Laravel and .NET**.

A large part of my work is in the **hosting industry**: billing and automation systems such as **WHMCS, WiseCP and HostBill**, control panel integrations with **cPanel, Plesk and DirectAdmin**, and the server infrastructure behind them.

### What I Do

- **Frontend development:** pixel-perfect, responsive and accessible interfaces with React, Vue.js, Alpine.js and Tailwind CSS.
- **Design systems:** reusable components, consistent theming with dark mode support, and clean, maintainable CSS architecture.
- **Performance:** fast-loading pages with optimized assets, lazy loading, modern build tooling and high Lighthouse scores.
- **Web applications:** scalable backends with Laravel and .NET, clean REST APIs and efficient database design.
- **Hosting automation:** custom themes, modules, provisioning and payment integrations for WHMCS, WiseCP, HostBill and Blesta.
- **Control panels:** cPanel/WHM, Plesk, DirectAdmin and CyberPanel setup, integration and automation.
- **Mail & DNS:** SmarterMail, Zimbra, Exim and Postfix mail servers, spam filtering and DNS management.
- **Infrastructure:** Linux and Windows servers, Nginx, Apache, LiteSpeed and IIS configuration, virtualization, monitoring, backups and security hardening.
