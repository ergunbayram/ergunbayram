### About Me

I'm a full-stack developer with **10+ years of experience** building and maintaining web products end to end. On the frontend I craft **pixel-perfect, responsive and accessible** interfaces with modern JavaScript frameworks and utility-first CSS; on the backend I work with **PHP, Laravel and .NET**.

A large part of my work is in the **hosting industry**: billing and automation systems such as **WHMCS, WiseCP and HostBill**, control panel integrations with **cPanel, Plesk and DirectAdmin**, and the Linux and Windows server infrastructure behind them.

### Core Expertise

| Area | What I Deliver |
| :-- | :-- |
| **Frontend Development** | Pixel-perfect, responsive and accessible interfaces; component-based architecture, design systems, dark mode and theming, smooth animations and cross-browser consistency. |
| **Backend Development** | Laravel and ASP.NET Core applications, REST and GraphQL APIs, authentication (OAuth 2.0, JWT), queues, caching and background jobs. |
| **Hosting Automation** | WHMCS, WiseCP, HostBill and Blesta themes, modules, provisioning, payment gateways, registrar integrations and client-area customization. |
| **Server Administration** | Linux and Windows servers, cPanel/WHM, Plesk and DirectAdmin; Nginx, Apache, LiteSpeed and IIS tuning; mail servers and DNS. |
| **Performance & SEO** | Core Web Vitals, asset optimization, caching layers, CDN configuration, structured data and technical SEO. |
| **Security & Reliability** | Server hardening, WAF and firewall rules, malware protection, SSL automation, monitoring and backup strategies. |
