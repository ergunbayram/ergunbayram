### About Me

I'm a full-stack developer with **10+ years of experience** building and maintaining web products end to end. On the backend I work with **PHP, Laravel and .NET**; on the frontend I build **responsive, accessible and high-performance** interfaces with modern HTML, CSS and JavaScript.

A large part of my work is in the **hosting industry**: client areas, billing and automation systems, custom **WHMCS** themes and modules, and the infrastructure behind them.

### What I Do

- **Web applications:** scalable backends with Laravel and .NET, clean REST APIs and efficient database design.
- **Frontend development:** responsive, accessible and fast interfaces with Tailwind CSS, Alpine.js and Vue.js.
- **Hosting & WHMCS:** custom themes, modules, client-area features and third-party integrations.
- **Infrastructure:** Linux servers, Nginx and Apache configuration, Cloudflare, caching and security hardening.
